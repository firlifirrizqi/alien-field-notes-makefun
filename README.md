# Alien Field Notes: The Two Day Earth Review

One alien tourist's review of planet Earth, written for the [Make.fun bounty](https://make.fun/bounty/u-swift-raven-16-alien-field-notes-the-two-day-earth-7647b000).

`main.py` writes the line to `/output/entry.txt`:

> ★★★★☆ — Lovely planet, breathtaking sunsets, but the locals charge rent to sleep on the rock they were born on. Would abduct again.

Run it with `python3 main.py`.
